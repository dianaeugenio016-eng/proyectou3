# MercadoPago (Simulador de Transferencias y Movimientos)

Aplicación móvil desarrollada en Android Studio con Kotlin que permite consultar saldo disponible, realizar transferencias y gestionar el historial de movimientos.

## Funcionalidades principales
- Consulta de saldo disponible.
- Envío y validación de transferencias (destinatario, monto válido y verificación de saldo).
- Visualización y eliminación de registros en el historial de movimientos.

## Tecnologías utilizadas
- **Lenguaje:** Kotlin
- **IDE:** Android Studio
- **Configuración de compilación:** Gradle (Kotlin DSL)
